# 六大核心服务内容重构计划

## 目标
将现有官网从五类概括性服务，调整为六项可对比、可深入阅读、可按需求分流的核心服务体系。保留当前“工程图纸 × 经典出版物”视觉与统一业务咨询入口，不引入 WordPress 或 ACF 依赖。

## 全站内容调整
- 首页服务区改为六项核心服务总览：数字营销战略、SEO 与 GEO、付费媒体、数据与营销分析、工业实体 AI 与 FDE、工业 B2B 社交媒体。
- 数字营销总览页增加六项服务的关系、实施顺序与适用边界，作为服务导航中枢。
- 复用现有服务地址承载 SEO/GEO、社交媒体与工业 AI；新增数字营销战略、付费媒体、数据分析三个独立详情页。
- 原“出海官网”内容保留为数字营销基础能力，并从总览与相关服务页建立入口，避免丢失已有有效内容。
- 导航、页脚、咨询表单和准备度自测的推荐方向同步更新为新的六项服务语言。

## 服务详情结构
每项服务统一采用以下信息层级：
1. 模块编码、英文标识、一句话摘要与适用客群。
2. 三项指标参数面板。
3. 三类现状困境，用于快速识别是否匹配。
4. 三项明章工程解法，并展示涉及的方法、平台或技术标准。
5. 三项核心交付物，以“交付物 / 载体 / 验收 / 预期影响”表格呈现。
6. 服务边界与动态咨询入口：出海增长进入通道 A，工业 AI 进入通道 B。

## 数据组织
- 将用户提供的 ACF 字段含义映射为项目内的类型化内容模型，集中维护六项服务数据。
- 字段覆盖编码、英文名、摘要、客群、指标、痛点、解法、交付物和咨询通道。
- 当前网站不是 WordPress，因此不安装 ACF Pro；页面表现与内容结构严格按该 Schema 实现，后续迁移到 WordPress 时可逐字段对应。

## 搜索与验证
- 为每个新增页面配置唯一标题、描述、Open Graph、Twitter Card、canonical 与 Service JSON-LD。
- 更新站点地图数据，确保新增地址被收录。
- 检查桌面与手机端的服务总览、详情表格、导航和两类咨询分流，并确认构建无错误。

## 内容准确性
- 用户给出的百分比、覆盖量和“趋近于 0”等指标均标注为项目目标或预期影响，不作为无条件效果承诺。
- 不增加未经提供的案例、客户名称、认证或经营数据。
