# Mingzhang Digital

System Prompt & Project Context: 明章 (Mingzhang Digital) 官网构建

You are going to build a complete, production-ready website for 温州明章数字科技有限公司（明章 / Mingzhang Digital）. Read all sections carefully before generating any code or copy. Apply the brand voice, visual tokens, SEO standards, and business logic consistently across every page and component.

Part 1. Starter Prompt & Operational Rules

Voice & Tone: 严谨直白（No-nonsense）、专业且具工业底色（Grounded & Expert）、真诚克制（Plain-spoken & Candid）。绝不使用泛滥的 SaaS 营销套话与夸大承诺（如“保证排名”、“保成交”、“万能 AI”）。

Look & Feel: 采用“明晰表达、信息成章”的理念。整体呈现一种深植于工程现场的秩序感与出版物般的版式美学，严谨、通透、克制，杜绝廉价模板感与刻板冰冷的科技蓝。

Workflow First: 严格遵循“先咨询了解真实需求，再匹配业务项目”的逻辑。全站以业务咨询与需求澄清为统一入口，而非直接推销标准套餐。

SEO & GEO Baked-in: 所有页面原生嵌入语义化 H1-H3、直接回答式段落（Direct Answer Format）、Schema.org 结构化数据与清晰的内链结构。

Competitors & Differentiation

传统建站外包与模板软件商:

Strengths: 交付快、价格低、模板库丰富。

Weaknesses: 毫无工业认知，页面千篇一律，缺少专业内容深度，建完即成死站。

How we differ: 将建站视为营销转化的承接底盘，深入企业制造工艺与技术规格，打通内容、搜索与销售线索链路。

泛行业出海代运营机构:

Strengths: 熟悉跨境电商/消费品社媒买量，打法敏捷。

Weaknesses: 用消费品思维做工业品，无法理解长决策周期、高客单价、多决策人的复杂 B2B 采购链路。

How we differ: 专注工业制造逻辑，围绕专业工程证据与技术方案构建信任，布局行业专业媒体与工程师圈层。

泛 AI 软件与概念集成商:

Strengths: 概念前沿，擅长演示酷炫的通用对话界面。

Weaknesses: 脱离企业现有系统与具体工作流，无法落地真实场景，无法处理业务异常。

How we differ: FDE 模式深入客户具体业务节点，从 1 个小型试点做起，验证任务质量、人工接管与维护交付。

Part 3. Visual Style Guide

Color Palette Tokens:

Primary (Text / Structure): #121314 (墨章黑，深沉墨色)

Secondary (Borders / Panels): #E5E1D8 (浅石灰) & #2A2D32 (炭石黑)

Background (Canvas): #F9F8F5 (绢纸暖白，温润有质感)

Accent (Focus / CTAs): #C85A32 (赭石陶橙，克制点睛)

Body Text: #242629 (深炭灰，高可读性)

Muted Text: #6B6E74 (铅灰色，说明文案)

Typography:

中文标题与正文：无衬线系统排版（PingFang SC, Hiragino Sans GB, 思源黑体），大标题字重 font-semibold，正文行高 leading-relaxed (1.75)。

编码、序号与标签：等宽字体（JetBrains Mono, Menlo, monospace），大写字母间距微调（tracking-wider）。

UI Patterns & Guidelines:

1px 秩序网格（Border Grid）：采用模块边框线（border border-[#E5E1D8]）形成如同设计手稿般的结构。

圆角规范：按钮与胶囊标签采用完全圆角（rounded-full），卡片容器采用柔和中圆角（rounded-xl 或 rounded-2xl），严禁尖锐硬边或过大的夸张卡通圆角。

按钮样式：

Primary CTA: 墨章黑底白字或赭石陶橙底白字（bg-[#121314] text-white hover:bg-[#C85A32]），圆润饱满。

Secondary CTA: 白底墨线（border border-[#E5E1D8] bg-white text-[#121314] hover:bg-[#F2EFEB]）。

严禁滥用：禁止使用刺眼的霓虹渐变、生硬的深色投影（Hard drop shadows）、金融科技风格的 3D 浮夸图标与无意义假大空库存图。

Part 4. SEO & AI Search (GEO) Best Practices

Site Architecture & URLs:

扁平结构，无冗余层级，所有页面从首页 3 次点击内到达。

标准格式：/digital-marketing/websites，/ai-implementation，/approach，/about，/contact。单词间统一用短横线（-）。

Title & Meta Standards:

Title 保持在 60 字符以内，核心关键词前置，末尾带品牌名（如：出海官网与转化体验设计 | 明章）。

Meta Description 保持在 100-120 字符，使用主动语态清晰阐述该页面解决的具体业务困扰。

Headings & Content Extraction:

每个页面严格唯一定义 1 个 <h1>。

<h2> 与 <h3> 必须为意图明确的实质性短句，而非“服务介绍”、“关于我们”等空泛词汇。

遵循直接回答规范（Direct Answer Format）：每个小标题下方第一句直接给出核心定义或答案，便于 Google AI Overviews、Perplexity 等生成式引擎直接抓取切片。

Structured Data (Schema.org JSON-LD):

首页配置 Organization 与 WebSite Schema，清晰标明温州明章数字科技有限公司及主要业务。

服务页面配置 Service Schema，包含提供方、服务类别与受众。

关于页配置 Person（创始人 Jiacheng Dai）与 AboutPage Schema，增强 E-E-A-T 权威信号。

Technical & Accessibility:

全站 HTTPS，移动端 100% 响应式自适应。

图片包含明确且具语境的 alt 描述文本，优先采用 WebP 格式与懒加载。

保持 robots.txt 对合法 AI 索引机器人（GPTBot, ClaudeBot, PerplexityBot, Google-Extended）开放抓取。
